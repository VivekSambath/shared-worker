01 · Overview

What is a SharedWorker?

  • Runs JavaScript in a background context
  • Shared by multiple browsing contexts
  • Tabs & windows talk to the same worker
  • Communication via MessagePort
  • Has its own execution context
  • Coordinate shared state & background work

main.js — each tab
const worker = new SharedWorker("worker.js");
worker.port.start();                  // needed with addEventListener
worker.port.postMessage("hello");
worker.port.onmessage = (e) => log(e.data);
worker.js — the shared worker
const ports = [];
onconnect = (e) => {                    // fires once per tab
  const port = e.ports[0];
  ports.push(port);
  port.onmessage = (ev) => ports.forEach(p => p.postMessage(ev.data));
};
